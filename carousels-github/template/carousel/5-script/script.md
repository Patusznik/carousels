# Script

Write or paste your slide text here. Rough notes or a voice-note transcript are fine too:
Claude helps you shape them in the brief. Leave it empty to write it together.

Format Claude understands (delete these examples):

Slide 1: Your hook, under 10 words

Slide 2: Raise the stakes
One or two short lines. Don't give away the answer yet.

Slide 3: A list slide
- first point
- second point

Optional tags inside a slide:
[PHOTO: IMG_2101]   use this photo (file name without extension)
[LAYOUT: quote]     force a layout
[STICKER: IMG_3417] you as a cut-out sticker

Blocks separated by a line with --- work too.
